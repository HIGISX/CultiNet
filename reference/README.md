# Reference Results

These files were copied from existing experiment outputs in the original workspace. The experiments were not rerun during packaging.

- `table_synthetic.csv` and `table_real.csv`: summary tables for six baseline methods using Euclidean distances and `M = 30, 50, 70`.
- `benchmark_runs.json`: 492 individual run records, including selected candidates, from the original Euclidean experiment checkpoint.
- `weight_sensitivity_results.csv` and `weight_sensitivity_solutions.json`: metrics and selected candidates for eight weight-sensitivity scenarios.
- `weight_ablation_results.csv` and `weight_ablation_solutions.json`: metrics and selected candidates for five objective-ablation scenarios.
- `user_M30_location_sets.json`: Xi'an candidate sequences for `M = 30`, supplied directly by the user, including a sequence labeled CultiNet. These candidate numbers are **one-based**. They were not generated by rerunning neural-model inference for this release.

In individual solver records, `selection` contains **zero-based** indices into the candidate array, following the candidate ID order used by the data loader. Use `selected_ids`, where available, to match selections to candidate IDs in the data tables. Original configuration, runtime, and optimality-certificate fields are preserved as recorded.
